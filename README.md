# テックの裏側。自動更新版

以前作成した白・水色のデザインとミケ／ロジの顔画像を引き継いだ、GitHub Pages向けサイトです。

## 無料で公開する手順

1. GitHubで**公開（Public）**リポジトリを作成します（例 `tech-no-uragawa`）。
2. このZIPを解凍し、**隠しフォルダ `.github` も含めて**リポジトリの `main` ブランチにアップロードします。GitHubのWebアップロードでは隠しフォルダが扱いにくい場合、GitHub Desktopやgitを使ってください。
3. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定します。
4. **Actions → ニュース自動更新と公開 → Run workflow** を実行します。
5. 成功後、Pages画面の公開URLを開きます。通常 `https://ユーザー名.github.io/リポジトリ名/` です。

## 動作

- GitHub Actionsが日本時間9:17と18:17を目安に起動（実際の実行は遅延する場合があります）。
- Google Developers / Google Japan Blog / GitHub Blog / Cloudflare Blogの公開RSSから最新記事を取得。
- 1回につき最大3件を追加。最大90件を保持。重複はURLで除外。
- RSSの見出しと概要を紹介し、ミケとロジの**定型会話**を自動作成します。**AIによる独自取材・本文検証・高度な生成ではありません**。
- RSS取得に失敗した場合は既存の記事を保持。新着がなければ追加しません。
- ソースリンクを必ず掲載します。RSSに記載された見出し・概要の利用条件は各配信元で確認してください。
- GitHub Pagesは静的サイトなのでコメントは引き続き端末内保存のみです。公開コメント機能は別途DB・認証・モデレーションが必要です。

## 費用・注意

公開リポジトリでGitHub Pagesと標準GitHub Actionsを使う構成。通常は無料枠で試せますが、サービスの規約・制限・料金は変更されます。独自ドメイン、外部AI API、DBは未使用。GitHubアカウントと初回設定は利用者が行います。GitHub Actionsのスケジュールは遅延・停止することがあり、無期限の稼働を保証しません。内容の定期確認は必要です。

## ローカルテスト

`python -m http.server 8000` で起動し、`http://localhost:8000` を開いてください。`file://` でHTMLを開くとfetchが制限され、デモ記事のみ表示される場合があります。

## 安全な運用

個人情報・秘密鍵をリポジトリに入れないでください。ニュース本文の無断転載は避け、記事の原文は必ずリンクで案内してください。自動投稿された記事の内容や表現は定期的に確認してください。
